# Visual assets

The bundled Echo white bear PNGs and app icon were generated with ImageGen for EchoSudoku. Each pose serves a specific context: thinking, resting, celebrating, diary, daily ritual or encouragement. The four medal faces are combined with native engraved patterns, colors, crests, milestone numerals and tier-dependent light.

All interface controls, charts, chessboard-like Sudoku grid, medal frames, solar rays and wave transformations are rendered in code. Tutorial screenshots are captured from the actual Android application with clearly designated teaching boards, not rendered design mockups.

Original private reference images and local generation/service receipts are not included. The Gradle wrapper retains its upstream license notices.
